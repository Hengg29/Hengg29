## Proyectos destacados

### [YOLO-Urban](https://github.com/Hengg29/YOLO-Urban)
App de detección de objetos urbanos construida con **YOLO11** y **Streamlit**. Procesa imágenes y video, identifica carros, autobuses, camiones, peatones, motos y semáforos, y permite elegir entre las cinco variantes del modelo (n / s / m / l / x) y ajustar el umbral de confianza desde la UI. Empacado en **Docker** para correrlo en cualquier máquina.

### Modelo de Igualación de Pintura
Sistema que predice códigos **RAL Classic** a partir de muestras de color, con preprocesamiento y reducción de ruido sobre el dataset. Pensado como base para aplicaciones reales de coincidencia de pintura automotriz.
